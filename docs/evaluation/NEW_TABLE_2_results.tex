    \item \textbf{ARIA\_CORE:} 3-tier reasoning (direct, 1-hop, 2-hop) with semantic retrieval
    \item \textbf{ARIA\_SEARCH:} ARIA\_CORE + real-time literature search (OpenAlex + Semantic Scholar)
    \item \textbf{ARIA\_FULL:} ARIA\_SEARCH + chain-of-thought transparency and confidence reporting
